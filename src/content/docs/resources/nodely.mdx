Nodely Sp. z o.o. is a third-party infrastructure provider that operates public `algod` and `indexer` endpoints for Algorand under the service name AlgoNode. Its free tier requires no registration or API token, which is why AlgoKit uses it as the default endpoint for TestNet and MainNet.

Nodely is not affiliated with or endorsed by the Algorand Foundation. Availability, limits, and pricing are set by Nodely and can change; this page records what their documentation states at the time of writing and links to the authoritative source for each figure.

## AlgoNode and Nodely

Both names refer to the same service. Nodely is the operating company; AlgoNode is the service brand, and it remains in use in several places:

- The `algonode.cloud` API hostnames, which Nodely documents as legacy but continues to serve.
- The `algonode.xyz` IPFS gateway hostname, which is current rather than legacy.
- AlgoKit Utils API names — `ClientManager.getAlgoNodeConfig()` in TypeScript and `ClientManager.get_algonode_config()` in Python.

Current documentation and the canonical API hostnames use the Nodely name.

## Free-Tier Endpoints

No token is required. Each endpoint listens on port 443.

| Network | Service | Endpoint                              |
| ------- | ------- | ------------------------------------- |
| MainNet | algod   | `https://mainnet-api.4160.nodely.dev` |
| MainNet | indexer | `https://mainnet-idx.4160.nodely.dev` |
| TestNet | algod   | `https://testnet-api.4160.nodely.dev` |
| TestNet | indexer | `https://testnet-idx.4160.nodely.dev` |
| BetaNet | algod   | `https://betanet-api.4160.nodely.dev` |
| BetaNet | indexer | `https://betanet-idx.4160.nodely.dev` |
| FNet    | algod   | `https://fnet-api.4160.nodely.dev`    |
| FNet    | indexer | `https://fnet-idx.4160.nodely.dev`    |

Nodely also publishes Tor onion endpoints for MainNet and TestNet. See the endpoint matrix for the full list.

### Legacy Hostnames

The older `algonode.cloud` hostnames remain in service. Nodely documents them as legacy endpoints running on the same infrastructure under the same rules, and has not published a retirement date.

| Network | algod                                | indexer                              |
| ------- | ------------------------------------ | ------------------------------------ |
| MainNet | `https://mainnet-api.algonode.cloud` | `https://mainnet-idx.algonode.cloud` |
| TestNet | `https://testnet-api.algonode.cloud` | `https://testnet-idx.algonode.cloud` |
| BetaNet | `https://betanet-api.algonode.cloud` | `https://betanet-idx.algonode.cloud` |

These are the hostnames AlgoKit resolves to when no endpoint is configured. `ClientManager.getAlgoNodeConfig()` in AlgoKit Utils returns an `algonode.cloud` URL, and `algokit project deploy testnet` and `algokit project deploy mainnet` derive their defaults from it. Projects that want the `4160.nodely.dev` hostnames must set `ALGOD_SERVER` and `INDEXER_SERVER` explicitly.

## Fair Usage Limits

The following apply to the free tier:

| Limit               | Value                                   |
| ------------------- | --------------------------------------- |
| Monthly requests    | 6,000,000                               |
| Daily requests      | 200,000                                 |
| Requests per second | 60 per user                             |
| Concurrent calls    | 10                                      |
| Added latency       | 150 ms, or 250 ms for archival requests |

Exceeding the per-second or concurrency limit returns HTTP 429; exceeding the daily request or byte quota returns HTTP 403. Nodely asks that clients apply exponential backoff after a 429 rather than retrying immediately.

Projects issuing more than one million requests per month are asked to credit Nodely on their site. Public-good projects can apply for an allowance above the free tier.

## Service Tiers

Nodely publishes four tiers for Algorand API access: **Free**, **Unlimited**, **Business**, and **Enterprise**. They differ in throughput, service level objective, dedicated versus shared infrastructure, and support response time. Current pricing and the per-tier limits are on Nodely's pricing page.

## Other Nodely Services

| Service            | Detail                                                                                                         |
| ------------------ | -------------------------------------------------------------------------------------------------------------- |
| Archival snapshots | Ledger snapshots for bootstrapping archival nodes, at `s3.nodely.io:9000/algo-snaps/`. Retained for three days |
| IPFS gateway       | `https://ipfs.algonode.xyz/ipfs/{cid}`, with `ipfs.algonode.dev` as a backup domain                            |
| Telemetry          | Third-party telemetry collection for node operators, the default provider in NodeKit                           |

Snapshots are supplied by a single third party and `algod` cannot verify their contents. Using one means trusting Nodely for that portion of chain history. Syncing an archival node from the network remains the verifiable option.

## Choosing Between Nodely and the Alternatives

The free tier suits development, testing, and low-traffic applications. Consider a paid tier, a different provider, or your own node when:

- Sustained traffic approaches the daily or monthly quota, or bursts past 60 requests per second.
- The added 150 ms free-tier latency is material to your application.
- You need a contractual service level rather than a best-effort public service.
- Query patterns or client addresses are sensitive enough that routing them through a third party is unacceptable.
- You need historical data beyond what the public indexer retains.

Other hosted Algorand API providers include [BlockDaemon](https://www.blockdaemon.com/protocols/algorand) and [GetBlock](https://getblock.io/nodes/algo/). To run your own instead, see [Algorand Node Types](/nodes/types) for hardware requirements and [Indexer Installation](/nodes/installation/indexer-installation) for historical queries.
