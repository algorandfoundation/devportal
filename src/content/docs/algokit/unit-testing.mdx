Algorand smart contracts can be unit tested offline, without a network or a running node. Each smart contract language has a companion testing library that emulates the AVM inside your normal test runner.

The testing guides are maintained with the libraries themselves, so they always match the version you install. This page links to them rather than copying them.

## TypeScript

`algorand-typescript-testing` runs Algorand TypeScript contracts inside test frameworks such as Vitest and Jest.
